---
name: open-auto-resume
description: Direct the user to the native Codex Auto Resume panel to schedule or manage follow-ups in a local Windows Codex thread.
---

Explain that the user can open Codex Auto Resume from the current conversation's side workspace using Show tabs (显示标签页) at the far right of the conversation header or `Ctrl+Shift+B`. On the New Tab page, open the menu beside Open and choose Codex Auto Resume. The same menu lets the user pin the entry for future chats. The panel verifies the current conversation or accepts its local link and lets the user confirm the schedule. For a missing runtime, direct them to run `Install-Panel.ps1` from the project directory.
