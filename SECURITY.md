# Security policy · 安全问题报告

Report suspected security vulnerabilities using the repository's [private vulnerability form](https://github.com/PanGucheng/CodexAutoResume-GUI/security/advisories/new). Include the affected version, impact and steps to reproduce. Use synthetic prompts and redact account details, credentials, and local paths from any logs you share.

For ordinary bugs and usability issues, use [GitHub Issues](https://github.com/PanGucheng/CodexAutoResume-GUI/issues).

发现安全漏洞时，请通过上方链接私下报告。请注明受影响的版本、影响范围和复现步骤，并用测试内容替代真实会话。
